Agent X Browser Bridge

Already installed? Update load karein: Chrome mein chrome://extensions kholein, Agent X Browser Bridge par Reload dabayein. Naye open/on commands ko bhi isi connected profile mein tab kholne ke liye yeh update chahiye. Phir project page refresh karein.

One-time setup for exact Chrome/Edge tab controls and YouTube pause/resume. The bridge works locally and uses no Groq API.

  1. Chrome mein chrome://extensions, ya Edge mein edge://extensions kholein.
  2. Developer mode on karein, phir Load unpacked dabayein.
  3. Yeh folder select karein: project ke andar ka browser-extension folder.
  4. Pairing: is page ko Agent X app ke "Chrome/Edge setup" link se kholein (URL mein token hota hai). Neeche status "Paired" dikhna chahiye. Bina pairing ke extension connect nahi hoga (badge PAIR).
  5. Project chalta rehne dein. Extension icon par click karein; badge ON ho jayega. Local network/localhost permission poochhi jaye to allow karein.

Sirf intended browser profile mein extension enable rakhein. Do profiles connected hon to agent tab guess nahi karega.

Try: video pause kar do, video chala do, Google Drive ka tab band kar do, YouTube ka tab band kar do, list tabs.

Multiple matching tabs hon to exact title ya displayed tab ID dein: close tab 123. Media controls use the real video paused/playing state; they do not blindly toggle Space.

The extension reads tab titles/URLs and can close the specifically selected tab. Script access is limited to YouTube playback controls. Incognito tabs are excluded. It sends data only to the local backend at 127.0.0.1:8000. Browser autoplay policies may require a manual Play click. The Codex in-app browser cannot load this Chrome/Edge extension.
